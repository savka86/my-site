# Пульс школы — кабинеты классных руководителей и завуча

Обновлено 10 ноября 2026. HTML: `puls-shkoly/index.html`. Серверная Edge Function: `puls-shkoly/supabase/functions/manage-teachers/index.ts`.

## Возможности

Завуч видит 25 классов и добавляет педагогов в разделе **«Классы и педагоги»**, вводя ФИО, email и класс. Защищённая функция **manage-teachers** проверяет JWT и роль `deputy` или `admin` в базе данных, отправляет приглашение по электронной почте, закрепляет класс и показывает нового педагога в списке. Учитель по ссылке в письме устанавливает личный пароль. Завуч не знает и не хранит пароль. Обычный педагог не получает доступ к управлению учетными записями.

## Обязательная первоначальная настройка

1. Опубликовать сайт через GitHub Pages репозитория `savka86/my-site`: **Settings → Pages → Deploy from a branch → main → / (root)**.
2. В Supabase **Authentication → URL Configuration** добавить Redirect URL `https://savka86.github.io/my-site/puls-shkoly/`. При использовании другого домена обновить также `SCHOOL_APP_URL` для Edge Function.
3. Создать в Supabase Authentication → Users первого завуча. Один раз из SQL Editor назначить ему роль (подставить фактические ФИО и email):
   ```sql
   update public.school_profiles set role='deputy', full_name='ФИО завуча'
   where id=(select id from auth.users where email='email@example.org')
   returning id,full_name,role;
   ```
4. Войти в кабинет завуча → «Классы и педагоги» → заполнить форму и отправить первое **тестовое** приглашение.
5. Настроить SMTP для надёжной доставки писем; проверить URL приглашения и установку пароля.

**Важно:** зарубежная тестовая база не предназначена для реальных персональных данных учеников и сотрудников. Для эксплуатации школы требуется согласованное защищённое размещение с учётом законодательства РФ.

Секретный ключ Supabase находится только на сервере. Клиентское приложение публикует только publishable API key.
